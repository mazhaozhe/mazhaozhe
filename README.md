# 四则运算生成器（Myapp）

一个用 Python 实现的小学四则运算题目命令行生成器：随机生成含自然数、真分数、带分数的四则运算题目，自动计算答案，并支持对给定的题目/答案文件判分统计。

## 功能特性

- 使用 `-n` 控制生成题目数量，`-r` 控制数值范围（必须给定，否则报错并输出帮助信息）
- 题目中运算符个数不超过 3 个；计算过程不出现负数；除法结果必为分数（不整除）、除数不为 0
- 通过"规范化表达式树"判重：交换 `+`、`×` 左右算式（含结合律重排）能互相变换的题目视为同一题
- 题目写入当前目录 `Exercises.txt`，答案写入 `Answers.txt`；真分数格式如 `3/5`，带分数格式如 `2'3/8`
- 支持对给定题目与答案文件判分统计（`-e` / `-a`），结果写入 `Grade.txt`
- 支持一次生成一万道题目（纯标准库实现，无第三方依赖）

## 运行环境

Python 3.8 及以上版本（仅使用标准库）。

## 使用方法

```bash
# 生成 10 道 10 以内（不含 10）的四则运算题目
python Myapp.py -n 10 -r 10

# 数值范围也可以是 1 或其他自然数；-n 缺省为 10
python Myapp.py -r 20

# 对给定题目与答案文件判分统计
python Myapp.py -e Exercises.txt -a Answers.txt
```

生成结果写入执行程序当前目录下的 `Exercises.txt` 与 `Answers.txt`：

```
(2 + 3) × 4 =
1/6 + 1/8 =
……
```

判分统计结果写入 `Grade.txt`：

```
Correct: 5 (1, 3, 5, 7, 9)
Wrong: 5 (2, 4, 6, 8, 10)
```

## 参数说明

| 参数 | 说明 |
| ---- | ---- |
| `-n <数量>` | 生成题目的个数，缺省为 10 |
| `-r <范围>` | 题目中数值（自然数、真分数分子与分母）的范围上限，**必须给定**。例如 `-r 10` 表示 10 以内（不含 10） |
| `-e <文件>` | 判题模式：题目文件路径，需与 `-a` 同时使用 |
| `-a <文件>` | 判题模式：答案文件路径，需与 `-e` 同时使用 |

## 需求实现说明

- **数值范围**：自然数取 `0 ~ r-1`；真分数、带分数的分子分母均小于 `r`；带分数（如 `1'1/2`）按题目定义同样属于"真分数"一类操作数。
- **除法约束**：形如 `e1 ÷ e2` 的子表达式，其结果必须是分数（不能整除），且除数不为 0。题目定义中真分数包含带分数形式，因此 `3 ÷ 2 = 1'1/2` 是合法题目，而 `4 ÷ 2 = 2`（结果为自然数）不合法。
- **判重策略**：将表达式树规范化为字符串键——`+`、`×` 节点的两个子键按字典序排序，`-`、`÷` 节点保持左右顺序。两棵表达式树能通过有限次交换 `+`/`×` 左右子树相互变换，当且仅当它们的规范化键相同。例如 `3 + (2 + 1)` 与 `1 + 2 + 3`（左结合等价于 `(1+2)+3`）判定为重复，而 `1 + 2 + 3` 与 `3 + 2 + 1` 不重复（结合结构不同，无法通过交换变换得到）。
- **范围过小时的退化**：若数值范围内不重复的合法题目少于 `-n`（例如 `-r 1` 时只有 80 余道），程序会报错提示增大 `-r`，而不会陷入死循环。

```bash
python -m unittest discover -s tests -v
```

测试覆盖：分数格式化与解析、约束校验（无负数、除法结果为分数、运算符个数）、判重等价性（含题目说明中给定的判定示例）、CLI 参数校验、判题统计，以及一万道题目的生成压测。

## 项目结构

```
Myapp.py                 # 命令行入口
myapp/
  fraction_utils.py      # 真分数/带分数的格式化与解析
  expression.py          # 表达式树：随机生成、约束求值、序列化、规范化判重
  generator.py           # 批量生成题目并写出 Exercises.txt / Answers.txt
  checker.py             # 题目解析、判题统计并写出 Grade.txt
  cli.py                 # 命令行参数解析与流程控制
tests/                   # 单元测试与功能测试
tools/
  benchmark.py           # 生成性能基准测试
```
